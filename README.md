# LehavimTransport
״יחד לאימון״ היא אפליקציה בעברית לתיאום הסעות לאימונים ולמשחקים עבור הורי גבעות בר, בקבוצה של עד שישה ילדים.  ההורים משבצים הסעות, מציינים מקומות פנויים ומעדכנים נוכחות בנפרד להלוך ולחזור. האפליקציה מציגה חוסרים במקומות ומאפשרת לנהל לוח שבועי ידנית או לייבא אותו מתמונה. היא מותאמת לטלפון ופועלת בקישור משותף ללא התחברות.
